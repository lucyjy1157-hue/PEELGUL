# PEELGUL

제주 표선 감귤 라이프스타일 브랜드 **PEELGUL**의 한국어 롱스크롤 홈페이지입니다.

PEELGUL은 귤을 까고, 향을 맡고, 맛보는 평범한 행동을 일상 속 짧은 감각의 전환으로 제안합니다. 메인 상품인 `Fresh Break Gift Set`은 제주 표선 감귤과 도자기 `Peel Bowl`, 선물 패키지로 구성되며, 이후 10kg·20kg 감귤 리필로 경험을 이어갈 수 있습니다.

## 주요 메시지

> 한 번의 Peel이, 하루의 결을 바꿉니다.

- **PEEL** — 껍질을 벗기며 잠시 멈추고
- **SCENT** — 퍼지는 시트러스 향으로 감각을 환기하고
- **TASTE** — 산뜻한 한 조각으로 기분을 전환합니다.

## 기술 구성

별도 프레임워크나 설치 과정 없이 실행되는 정적 웹사이트입니다.

- `index.html` — 한국어 페이지 구조, 검색·소셜 메타데이터
- `styles.css` — 에디토리얼 디자인과 반응형 레이아웃
- `script.js` — 스크롤 헤더, 등장 모션, 임시 구매 링크 처리
- `assets/` — 브랜드 이미지, 메타 이미지, 파비콘

## 실행 방법

가장 간단한 방법은 `index.html`을 브라우저에서 여는 것입니다.

로컬 서버에서 확인하려면 이 폴더에서 아래 명령을 실행합니다.

```bash
ruby -run -ehttpd . -p 4173
```

그다음 브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 이미지와 메타데이터

- `assets/peelgul-og.png` — 1200×630 소셜 공유용 메타 이미지
- `assets/favicon.png` — 고해상도 원본 파비콘
- `assets/favicon-32.png` — 브라우저 탭용 32×32 파비콘
- `assets/apple-touch-icon.png` — iOS 홈 화면용 180×180 아이콘
- `assets/01_hero_peel.png` — 고화질 보정 히어로 이미지
- `assets/02_fresh_break_lifestyle.png` — 고화질 보정 라이프스타일 이미지

나머지 제품·도자기·농장·선물 이미지는 원본 자체가 웹용 고화질 기준을 충족해 원본 화질을 유지했습니다.

## 구매 링크 연결

현재 구매와 리필 버튼은 디자인 확인용 임시 링크입니다. 실제 판매 주소가 준비되면 `index.html`에서 아래 속성을 가진 링크의 `href`를 교체하고 `data-link-placeholder` 속성을 제거합니다.

```html
data-link-placeholder="purchase-link"
data-link-placeholder="refill-link"
```

링크를 연결한 뒤 `script.js` 하단의 임시 링크 클릭 방지 코드를 제거하세요.

## 반응형 지원

- 데스크톱: 대형 이미지와 비대칭 텍스트 구성을 사용합니다.

- `prefers-reduced-motion` 환경에서는 등장 애니메이션이 비활성화됩니다.
