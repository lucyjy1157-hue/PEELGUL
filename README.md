# PEELGUL3

제주 표선 감귤과 `Peel Bowl`을 중심으로 구성한 한국어 브랜드 랜딩페이지입니다. 감귤을 까는 짧은 행동을 하루의 산뜻한 휴식인 **Fresh Break**로 제안합니다.

## 주요 구성

- 브랜드 메시지를 강조한 대형 타이포그래피 히어로
- Fresh Break의 `PEEL · SCENT · TASTE` 리추얼 소개
- 감귤의 향·산미·단맛 균형과 Peel Bowl 설명
- 제주 표선 2대 농장 이야기
- Fresh Break Gift Set 구성과 상품 이미지 갤러리
- 10kg·20kg 감귤 리필 옵션
- 모바일 메뉴, 스크롤 진행 표시, 등장 애니메이션, 구매 안내 알림

## 파일 안내

- `index.html` — 페이지 구조와 한국어 콘텐츠, 검색·공유 메타 정보
- `styles.css` — 반응형 레이아웃, 브랜드 컬러, 타이포그래피와 모션
- `script.js` — 모바일 메뉴, 스크롤 효과, 상품 갤러리와 구매 안내
- `assets/` — 원본 고화질 사진, 메타 이미지, 파비콘

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하는 경우 이 폴더에서 정적 파일 서버를 실행하세요.
